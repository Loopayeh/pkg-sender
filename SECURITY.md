# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security problems.

Report privately via GitHub Security Advisories on this repo
(`Security` tab → `Report a vulnerability`), or contact the maintainer
through the links at https://loopayeh.github.io/.

Include: affected version, console firmware, steps to reproduce,
and logs if available. We aim to acknowledge within 72 hours.
